# Aleksandr Petrakov

Personal portfolio website for Aleksandr Petrakov, Senior Frontend Technical Lead / Frontend Architect.

Live site: [https://alekspetrakov.github.io](https://alekspetrakov.github.io)

## About

This repository contains the production build of my personal portfolio website published via GitHub Pages.

The source code is maintained separately and deployed here as a static build.

## Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- GitHub Pages

## Repository Purpose

This repository is used only as the public hosting target for GitHub Pages.

Generated static assets are published here automatically from the source project.

Recruiters and hiring teams are welcome to view and share the live website URL.
